在以下步骤中，我们将说明如何组装 Koch v1.1 机器人。

## 订购并组装部件[[order-and-assemble-the-parts]]

请遵循此 [README](https://github.com/jess-moss/koch-v1-1) 中提供的采购和组装说明。它将指导你设置从臂（follower arm）和主臂（leader arm），如下图所示。

关于组装过程的可视化演示，你可以参考[此视频教程](https://youtu.be/8nQIg9BwwTk)。

> [!WARNING]
> 自该视频制作以来，我们简化了配置阶段。因此，有两处与视频中的说明不同：
>
> - 不要立即插上所有电机线缆，请等待在[配置电机](#configure-the-motors)中收到相关指示后再操作。
> - 不要立即将控制板（PCB）拧到底座上，请等待在[配置电机](#configure-the-motors)中收到相关指示后再操作。

## 安装 LeRobot 🤗[[install-lerobot]]

要安装 LeRobot，请遵循我们的[安装指南](./installation)。

除了这些说明之外，你还需要安装 Dynamixel SDK：

```bash
pip install -e ".[dynamixel]"
```

## 配置电机[[configure-the-motors]]

### 1. 查找每个机械臂关联的 USB 端口[[1-find-the-usb-ports-associated-with-each-arm]]

要找到每个总线舵机适配器的端口，请运行此脚本：

```bash
lerobot-find-port
```

<hfoptions id="example">
<hfoption id="Mac">

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
Remove the USB cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/tty.usbmodem575E0032081
Reconnect the USB cable.
```

找到的端口是：`/dev/tty.usbmodem575E0032081`，它对应你的主臂或从臂。

</hfoption>
<hfoption id="Linux">

在 Linux 上，你可能需要通过运行以下命令来授予 USB 端口访问权限：

```bash
sudo chmod 666 /dev/ttyACM0
sudo chmod 666 /dev/ttyACM1
```

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/ttyACM0', '/dev/ttyACM1']
Remove the usb cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/ttyACM1
Reconnect the USB cable.
```

找到的端口是：`/dev/ttyACM1`，它对应你的主臂或从臂。

</hfoption>
</hfoptions>

### 2. 设置电机 ID 和波特率[[2-set-the-motors-ids-and-baudrates]]

每个电机在总线上都有一个唯一 ID。全新电机通常带有默认 ID `1`。为了使电机与控制器之间的通信正常工作，我们首先需要为每个电机设置一个不同的唯一 ID。此外，数据在总线上的传输速度由波特率决定。为了能够相互通信，控制器和所有电机都需要配置为相同的波特率。

为此，我们首先需要让控制器单独连接每个电机，以便设置这些参数。由于我们会将这些参数写入电机内部存储器的非易失性区域（EEPROM），因此只需执行一次。

如果你要重新使用来自其他机器人的电机，可能也需要执行此步骤，因为 ID 和波特率很可能不匹配。

#### 从臂[[follower]]

将 USB 线缆从你的电脑以及 5V 电源连接到从臂的控制板。然后，使用你在上一步中获得的端口运行以下命令，或运行 API 示例。你还需要使用 `id` 参数为主臂命名。

有关如何设置电机 ID 的可视化参考，请参阅[此视频](https://huggingface.co/docs/lerobot/zh-hans/so101#setup-motors-video)，其中我们演示了 SO101 机械臂的流程。

<hfoptions id="setup_motors">
<hfoption id="Command">

```bash
lerobot-setup-motors \
    --robot.type=koch_follower \
    --robot.port=/dev/tty.usbmodem575E0031751 # <- 在此粘贴上一步找到的端口
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.koch_follower import KochFollower, KochFollowerConfig

config = KochFollowerConfig(
    port="/dev/tty.usbmodem575E0031751",
    id="my_awesome_follower_arm",
)
follower = KochFollower(config)
follower.setup_motors()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

你应该会看到以下指令。

```
Connect the controller board to the 'gripper' motor only and press enter.
```

按照指示，插上夹爪（gripper）的电机。请确保它是唯一连接到控制板的电机，并且该电机本身尚未以菊花链方式连接到任何其他电机。当你按 `[Enter]` 时，脚本将自动为该电机设置 ID 和波特率。

<details>
<summary>故障排除</summary>

如果此时遇到错误，请检查线缆并确保它们已正确插入：

<ul>
  <li>电源</li>
  <li>你的电脑与控制板之间的 USB 线缆</li>
  <li>从控制板到电机的 3 针线缆</li>
</ul>

如果你使用的是 Waveshare 控制板，请确保两个跳线均设置在 `B` 通道（USB）上。

</details>

然后你应该会看到以下消息：

```
'gripper' motor id set to 6
```

接着是下一条指令：

```
Connect the controller board to the 'wrist_roll' motor only and press enter.
```

你可以从控制板上断开 3 针线缆，但另一端可以保持连接到夹爪电机，因为它已经位于正确的位置。现在，将另一根 3 针线缆插到腕部旋转（wrist roll）电机，并将其连接到控制板。与之前的电机一样，请确保它是唯一连接到控制板的电机，并且该电机自身没有连接到任何其他电机。

按照指示对每个电机重复此操作。

> [!TIP]
> 在按 Enter 之前，请检查每一步的线缆连接。例如，在操作控制板时，电源线可能会断开。

完成后，脚本会直接结束，此时电机即可使用。现在，你可以将每个电机的 3 针线缆连接到下一个电机，并将第一个电机（'shoulder pan'，id=1）的线缆连接到控制板；随后控制板就可以安装到机械臂底座上。

#### 主臂[[leader]]

为主臂执行相同步骤，但相应修改命令或脚本。

```bash
    --teleop.type=koch_leader \
    --teleop.port=/dev/tty.usbmodem575E0031751 \  # <- 在此粘贴上一步找到的端口
```

</hfoption>

## 校准[[calibrate]]

接下来，你需要校准机器人，以确保主臂和从臂在处于相同物理位置时具有相同的位置值。
校准过程非常重要，因为它可以让在一个机器人上训练的神经网络在另一个机器人上工作。

#### 从臂[[follower]]

运行以下命令或 API 示例来校准从臂：

<hfoptions id="calibrate_follower">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --robot.type=koch_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \ # <- 你机器人的端口
    --robot.id=my_awesome_follower_arm  # <- 为机器人指定一个唯一名称
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.koch_follower import KochFollowerConfig, KochFollower

config = KochFollowerConfig(
    port="/dev/tty.usbmodem585A0076891",
    id="my_awesome_follower_arm",
)

follower = KochFollower(config)
follower.connect(calibrate=False)
follower.calibrate()
follower.disconnect()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

我们统一了大多数机器人的校准方法。因此，此 Koch 机械臂的校准步骤与 SO100 和 SO101 的步骤相同。首先，我们必须将机器人移动到每个关节都处于其活动范围中间的位置，然后按 `Enter`。其次，我们让所有关节完成其完整运动范围。可在此处找到 SO101 相同过程的参考视频：[此处](https://huggingface.co/docs/lerobot/zh-hans/so101#calibration-video)。

#### 主臂[[leader]]

对主臂执行相同步骤进行校准，运行以下命令或 API 示例：

<hfoptions id="calibrate_leader">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --teleop.type=koch_leader \
    --teleop.port=/dev/tty.usbmodem58760431551 \ # <- 你机器人的端口
    --teleop.id=my_awesome_leader_arm  # <- 为机器人指定一个唯一名称
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.teleoperators.koch_leader import KochLeaderConfig, KochLeader

config = KochLeaderConfig(
    port="/dev/tty.usbmodem575E0031751",
    id="my_awesome_leader_arm",
)

leader = KochLeader(config)
leader.connect(calibrate=False)
leader.calibrate()
leader.disconnect()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>
