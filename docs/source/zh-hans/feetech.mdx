# 飞特舵机固件更新[[feetech-motor-firmware-update]]

本教程将指导你使用飞特（Feetech）官方软件更新飞特舵机的固件。

## 前置要求[[prerequisites]]

- Windows 电脑（飞特软件仅可在 Windows 上运行）
- 飞特舵机控制板
- 用于将控制板连接到电脑的 USB 线缆
- 连接到控制板上的飞特舵机

## 步骤 1：下载飞特软件[[step-1-download-feetech-software]]

1. 访问飞特官方软件下载页面：[https://www.feetechrc.com/software.html](https://www.feetechrc.com/software.html)
2. 下载最新版本的飞特调试软件（FD）
3. 在 Windows 电脑上安装该软件

## 步骤 2：硬件设置[[step-2-hardware-setup]]

1. 将飞特舵机连接到舵机控制板
2. 通过 USB 线缆将舵机控制板连接到 Windows 电脑
3. 确保为舵机供电

## 步骤 3：配置连接[[step-3-configure-connection]]

1. 启动飞特调试软件
2. 从端口下拉菜单中选择正确的 COM 端口
   - 如果不确定使用哪个端口，请检查 Windows 设备管理器中的“端口（COM & LPT）”
3. 设置适当的波特率（对于大多数飞特舵机，通常为 1000000）
4. 点击“打开”以建立与控制板的通信

## 步骤 4：扫描舵机[[step-4-scan-for-motors]]

1. 连接后，点击“搜索”按钮以检测所有已连接的舵机
2. 软件将自动发现并列出总线上的所有舵机
3. 每个舵机将显示其 ID 编号

## 步骤 5：更新固件[[step-5-update-firmware]]

对于每个要更新的舵机：

1. **选择舵机**，在列表中点击它
2. **点击“升级”选项卡**：
3. **点击“在线”按钮**：
   - 如果发现可能的固件更新，则会显示在框中。
4. **点击“升级”按钮**：
   - 将显示更新进度

## 步骤 6：验证更新[[step-6-verify-update]]

1. 更新完成后，软件应自动刷新舵机信息
2. 确认固件版本已更新到预期版本

## 重要说明[[important-notes]]

⚠️ **警告**：不要在固件更新期间断开电源或 USB，这可能会导致舵机变砖。

## 附加内容：在 Linux/macOS 上调试舵机[[bonus-motor-debugging-on-linuxmacos]]

仅出于调试目的，你可以使用开源的 Feetech 调试工具：

- **仓库**：[FT_SCServo_Debug_Qt](https://github.com/CarolinePascal/FT_SCServo_Debug_Qt/tree/fix/port-search-timer)

### 安装说明[[installation-instructions]]

请按照仓库中的说明安装该工具。对于 Ubuntu，可以直接安装；对于 macOS，需要从源代码构建。

**限制：**

- 此工具仅用于调试和参数调整
- 固件更新仍必须在 Windows 上使用官方 Feetech 软件进行。
