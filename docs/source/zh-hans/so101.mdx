## 安装 LeRobot 🤗[[install-lerobot]]

要安装 LeRobot，请遵循我们的[安装指南](./installation)

除这些说明外，你还需要安装 Feetech SDK：

```bash
pip install -e ".[feetech]"
```

## 分步组装说明[[step-by-step-assembly-instructions]]

从臂（follower arm）使用 6 个 1/345 减速比的 STS3215 电机。然而，主臂（leader arm）使用三个不同减速比的电机，以确保它既能承受自身重量，又能不需要太大力气即可移动。下表显示了每个关节需要哪个电机。

| 主臂轴          | 电机 | 齿轮比  |
| --------------- | :--: | :-----: |
| 底座 / 肩部平移 |  1   | 1 / 191 |
| 肩部抬升        |  2   | 1 / 345 |
| 肘部弯曲        |  3   | 1 / 191 |
| 腕部弯曲        |  4   | 1 / 147 |
| 腕部滚转        |  5   | 1 / 147 |
| 夹爪            |  6   | 1 / 147 |

## 配置电机[[configure-the-motors]]

### 1. 查找与每个臂关联的 USB 端口[[1-find-the-usb-ports-associated-with-each-arm]]

要查找每个总线舵机适配器的端口，请通过 USB 和电源将 MotorBus 连接到计算机。运行以下脚本，并在提示时断开 MotorBus：

```bash
lerobot-find-port
```

<hfoptions id="example">
<hfoption id="Mac">

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
Remove the USB cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/tty.usbmodem575E0032081
Reconnect the USB cable.
```

找到的端口是：`/dev/tty.usbmodem575E0032081`，它对应你的主臂或从臂。

</hfoption>
<hfoption id="Linux">

在 Linux 上，你可能需要通过运行以下命令来授予 USB 端口访问权限：

```bash
sudo chmod 666 /dev/ttyACM0
sudo chmod 666 /dev/ttyACM1
```

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/ttyACM0', '/dev/ttyACM1']
Remove the usb cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/ttyACM1
Reconnect the USB cable.
```

找到的端口是：`/dev/ttyACM1`，它对应你的主臂或从臂。

</hfoption>
</hfoptions>

### 2. 设置电机 ID 和波特率[[2-set-the-motors-ids-and-baudrates]]

每个电机在总线上都由一个唯一 ID 标识。全新电机通常带有默认 ID `1`。为了让电机与控制器之间正常通信，我们首先需要为每个电机设置一个不同的唯一 ID。此外，总线上数据传输的速度由波特率决定。为了相互通信，控制器和所有电机都需要配置相同的波特率。

为此，我们首先需要让控制器逐个连接每个电机来设置这些参数。由于我们会把这些参数写入电机内部存储器（EEPROM）的非易失性区域，因此只需执行一次。

如果你要复用来自另一个机器人的电机，很可能也需要执行此步骤，因为 ID 和波特率大概率不匹配。

下面的视频展示了设置电机 ID 的步骤顺序。

#### 从臂[[follower]]

将计算机的 USB 线缆和电源连接到从臂的控制器板。然后，使用上一步获取的端口运行以下命令，或运行 API 示例。你还需要通过 `id` 参数为从臂指定一个名称。

<hfoptions id="setup_motors">
<hfoption id="Command">

```bash
lerobot-setup-motors \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem585A0076841  # <- 在此粘贴上一步找到的端口
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.so_follower import SO101Follower, SO101FollowerConfig

config = SO101FollowerConfig(
    port="/dev/tty.usbmodem585A0076841",
    id="my_awesome_follower_arm",
)
follower = SO101Follower(config)
follower.setup_motors()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

你应该会看到以下指示

```bash
Connect the controller board to the 'gripper' motor only and press enter.
```

按照指示，插入夹爪电机。确保它是唯一连接到板上的电机，并且该电机尚未与其他任何电机以菊花链方式连接。当你按下 `[Enter]` 时，脚本会自动为该电机设置 ID 和波特率。

<details>
<summary>故障排除</summary>

如果此时遇到错误，请检查线缆并确保它们正确插入：

<ul>
  <li>电源</li>
  <li>计算机与控制器板之间的 USB 线缆</li>
  <li>从控制器板到电机的 3 针线缆</li>
</ul>

如果你使用的是 Waveshare 控制器板，请确保两个跳线帽设置在 `B` 通道（USB）上。

</details>

然后你应该会看到以下消息：

```bash
'gripper' motor id set to 6
```

接着是下一条指示：

```bash
Connect the controller board to the 'wrist_roll' motor only and press enter.
```

你可以从控制器板上断开 3 针线缆，但另一端可以保持连接到夹爪电机，因为它已经位于正确的位置。现在，将另一根 3 针线缆插入腕部滚转电机，并连接到控制器板。与上一个电机一样，确保它是唯一连接到板上的电机，并且该电机本身没有连接到任何其他电机。

按照指示对每个电机重复此操作。

> [!TIP]
> 在每一步按 Enter 之前检查线缆。例如，在操作板子时，电源线可能会断开。

完成后，脚本会直接结束，此时电机就可以使用了。现在，你可以将每个电机的 3 针线缆连接到下一个电机，并将第一个电机（`id=1` 的 `shoulder pan`）的线缆连接到控制器板，然后就可以将控制器板安装到机械臂底座上。

### 清理零件[[clean-parts]]

从 3D 打印零件上移除所有支撑材料。最简单的方法是用小螺丝刀从支撑材料下方撬起。

建议在放置电机后、继续组装前，先在电机中装好一根 3 针线缆。

### 关节 1[[joint-1]]

- 安装两个电机舵盘（motor horn）。用一颗 M3x6mm 螺丝固定上方舵盘。下方舵盘无需螺丝。
- 将第一个电机放入底座。
- 用 4 颗 M2x6mm 螺丝（最小的螺丝）固定电机。顶部两颗，底部两颗。
- 滑上第一个电机支架，并用两颗 M2x6mm 螺丝固定（每侧一颗）。
- 安装肩部部件。
- 用顶部 4 颗 M3x6mm 螺丝和底部 4 颗 M3x6mm 螺丝拧紧肩部部件
- 安装肩部电机支架。

## 校准[[calibrate]]

接下来，你需要校准机器人，以确保主臂和从臂处于相同物理位置时具有相同的位置值。
校准过程非常重要，因为它能让在一个机器人上训练的神经网络在另一个机器人上工作。

#### 从臂[[follower]]

运行以下命令或 API 示例来校准从臂：

<hfoptions id="calibrate_follower">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \ # <- 你的机器人端口
    --robot.id=my_awesome_follower_arm # <- 为机器人指定唯一名称
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.so_follower import SO101FollowerConfig, SO101Follower

config = SO101FollowerConfig(
    port="/dev/tty.usbmodem585A0076891",
    id="my_awesome_follower_arm",
)

follower = SO101Follower(config)
follower.connect(calibrate=False)
follower.calibrate()
follower.disconnect()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

下面的视频展示了如何执行校准。首先，你需要将机器人移动到所有关节都处于其运动范围中间的位置。然后按下 Enter 后，你需要让每个关节完成整个运动范围。
