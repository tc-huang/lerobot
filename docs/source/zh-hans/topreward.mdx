# TOPReward[[topreward]]

TOPReward 是一个**零样本奖励模型（zero-shot reward model）**，它从现成的视觉语言模型（VLM）中提取 token 对数概率，作为机器人奖励信号。给定视频轨迹和任务指令后，它会返回 VLM 对指令为真的对数似然——无需微调。

**论文**：[TOPReward: Token Probabilities as Hidden Zero-Shot Rewards for Robotics](https://arxiv.org/abs/2602.19313)
**项目**：[topreward.github.io](https://topreward.github.io/webpage/)
**原始代码**：[github.com/TOPReward/TOPReward](https://github.com/TOPReward/TOPReward)
**默认主干模型**：[Qwen/Qwen3-VL-8B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct)

## 概述[[overview]]

TOPReward 会询问一个通用 VLM：**以机器人尝试完成该任务的视频为条件**，一条任务指令成立的可能性有多大。具体而言，给定：

- 一段轨迹视频（由一系列帧组成）。
- 一条任务指令（例如 _“打开抽屉”_）。

它会构建如下形式的聊天提示词：

```text
<video>
"The above video shows a robot manipulation trajectory that completes the
 following task: <instruction> Decide whether the above statement is True
 or not. The answer is: True"
```

将其前向传播通过 VLM，对除最后一个 token 之外的所有内容进行标签掩码，然后读回该 token 的对数概率——默认是用于收尾后缀模板的字面量 `"True"`。由此得到的 `log P("True" | video + prompt + instruction)` 就是奖励。

由于该方法仅依赖于一个冻结的 VLM，TOPReward 是**零样本**的：没有需要托管的微调权重。LeRobot 中的“模型”是围绕 `transformers` 的 `Qwen3VLForConditionalGeneration` 加上标签掩码逻辑的一层小型封装。处理器持有分词器（tokeniser），并构建完整的聊天提示词（EO-1/Robometer 模式）。

## LeRobot 集成涵盖的内容[[what-the-lerobot-integration-covers]]

- 通过 LeRobot 进行标准的 `reward_model.type=topreward` 配置。
- 通过 `transformers` 的 `Qwen3VLForConditionalGeneration` API 加载 VLM。
- 在处理器中组装提示词并进行分词（与上游 `QwenClient.compute_instruction_reward` 一致）。
- `compute_reward()` 为每个样本返回一个标量对数概率。
- LeRobot 奖励模型保存/加载——`save_pretrained` 仅写入 `config.json`（VLM 由 `vlm_name` 标识）。
- 一个离线标注脚本，用于为 RA-BC 和叠加（overlay）写入 `topreward_progress.parquet`（SARM 兼容 schema）。

当前 LeRobot 移植版**仅支持 Qwen3-VL 客户端**。其他上游客户端（Gemini、OpenAI、Gemma、Molmo）可作为后续扩展项添加。

## 安装要求[[installation-requirements]]

1. 按照[安装指南](./installation)安装 LeRobot。
2. 安装 TOPReward 可选附加项：

```bash
pip install -e ".[topreward]"
```

或者，在源码检出目录中使用 `uv`：

```bash
uv sync --extra topreward
```

这会引入 `transformers`。首次运行 TOPReward 时，Hugging Face 还会从 Hub 下载 VLM 权重（Qwen3-VL-8B-Instruct 约 16 GB）。强烈建议使用 GPU。

## 模型输入与输出[[model-inputs-and-outputs]]

TOPReward 期望：

- 一段轨迹视频或一系列帧。
- 一段自然语言任务描述。

在 LeRobot 数据集中，预处理器会读取：

| 配置字段                  | 默认值                      | 含义                            |
| ------------------------- | --------------------------- | ------------------------------- |
| `reward_model.image_key`  | `observation.images.top`    | TOPReward 使用的相机观测        |
| `reward_model.task_key`   | `task`                      | 互补数据中任务字符串对应的键    |
| `reward_model.max_frames` | `16`                        | 每个样本的帧数上限              |
| `reward_model.fps`        | `2.0`                       | 传递给 Qwen 视频处理器的元数据  |
| `reward_model.vlm_name`   | `Qwen/Qwen3-VL-8B-Instruct` | 底层 VLM 的 Hugging Face Hub id |

模型返回：

- `compute_reward(batch)`：每个样本返回一个对数概率。数值越高 = 任务与视频的对齐程度越好。当 `success_threshold` 为有限值时，改为返回二值化阈值结果。

## 用法[[usage]]

### 直接加载奖励模型[[load-the-reward-model-directly]]

```python
from lerobot.rewards.topreward import TOPRewardConfig, TOPRewardModel

cfg = TOPRewardConfig(
    vlm_name="Qwen/Qwen3-VL-8B-Instruct",
    device="cuda",
)
reward_model = TOPRewardModel(cfg)
```

### 使用奖励模型工厂[[use-the-reward-factory]]

```python
from lerobot.rewards import make_reward_model, make_reward_model_config, make_reward_pre_post_processors

cfg = make_reward_model_config(
    "topreward",
    vlm_name="Qwen/Qwen3-VL-8B-Instruct",
    device="cuda",
    image_key="observation.images.top",
)
reward_model = make_reward_model(cfg)
preprocessor, postprocessor = make_reward_pre_post_processors(cfg)
```

预处理器会对完整提示词（视频 + 前缀 + 指令后缀）进行分词，将 Qwen-VL 张量 + `prompt_length` 写入 `observation.topreward.*`。模型读取这些张量，基于 `prompt_length` 进行标签掩码，并提取对数概率奖励。

### 离线数据集标注[[offline-dataset-labeling]]

为 RA-BC 训练和叠加视频写入一个 `topreward_progress.parquet`：

```bash
# Sparse-dense（每个片段 15 个锚点，与上游一致）
uv run python -m lerobot.rewards.topreward.compute_rabc_weights \
    --dataset-repo-id lerobot/libero_10_image \
    --num-samples 15 \
    --device cuda
```

然后为任意片段渲染进度叠加视频：

```bash
uv run examples/dataset/create_progress_videos.py \
    --repo-id lerobot/libero_10_image \
    --episode 0 \
    --progress-file topreward_progress.parquet \
    --gif
```

## 配置说明[[configuration-notes]]

### 提示词可调项[[prompt-knobs]]

默认提示词与上游论文一致：

```text
prompt_prefix = "The above video shows a robot manipulation trajectory that completes the following task: "
prompt_suffix_template = "{instruction} Decide whether the above statement is True or not. The answer is: True"
```

两者都在 `TOPRewardConfig` 上公开，以便进行消融实验。后缀模板**必须**包含 `{instruction}`。

### 对话模板[[chat-template]]

`add_chat_template=True` 会在分词前，使用分词器的对话模板包裹完整提示词（包括指令）。默认值为 `False`，与上游论文的主要实验一致。

## 局限性[[limitations]]

- 当前 LeRobot 移植版**仅支持推理且为零样本**；未重写 `forward()`，且 `is_trainable` 返回 `False`。
- 仅支持 **Qwen3-VL 系列**；其他上游客户端不在范围内。
- TOPReward 会继承底层 VLM 的偏差。
