# 安装[[installation]]

本指南使用 `conda`（通过 miniforge）来管理环境（推荐使用）。如果您倾向于使用其他环境管理工具（例如 `uv`、`venv`），请确保您的 Python >=3.12 且支持 PyTorch >= 2.10，然后直接跳转到[环境配置](#step-2-environment-setup)部分。

## 步骤 1（仅限 `conda`）：安装 [`miniforge`](https://conda-forge.org/download/)[[step-1-conda-only-install-miniforge]]

```bash
wget "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh
```

## 步骤 2：环境配置[[step-2-environment-setup]]

创建一个使用 Python 3.12 的虚拟环境：

<!-- prettier-ignore-start -->
<hfoptions id="create_venv">
<hfoption id="conda">
```bash
conda create -y -n lerobot python=3.12
```
</hfoption>
<hfoption id="uv (PyTorch >= 2.10 only)">
```bash
uv python install 3.12
uv venv --python 3.12
```
</hfoption>
</hfoptions>
<!-- prettier-ignore-end -->

然后激活您的虚拟环境，每次打开终端窗口使用 lerobot 时都需要执行此操作：

<!-- prettier-ignore-start -->

<hfoptions id="activate_venv">
<hfoption id="conda">

```

> conda install evdev -c conda-forge

source .venv/bin/activate

.venv\Scripts\activate
```

> [!NOTE]

### 安装 `ffmpeg`（用于视频解码）[[install-ffmpeg-for-video-decoding]]

LeRobot 默认使用 [TorchCodec](https://github.com/meta-pytorch/torchcodec) 进行视频解码，这需要 `ffmpeg`。

> [!NOTE]
> **平台支持：** TorchCodec 在 macOS Intel（x86_64）、Linux ARM（aarch64、arm64、armv7l）或使用 PyTorch < 2.8 的 Windows 平台上**不可用**。在这些平台上，LeRobot 会自动回退到 `pyav` —— 因此您无需安装 `ffmpeg`，可以直接跳至步骤 3。
>
> **Jetson（aarch64 + CUDA）：** 上述 `pyav` 回退意味着默认情况下无法进行 GPU 加速的视频解码。[`docker/Dockerfile.jetson`](https://github.com/huggingface/lerobot/blob/main/docker/Dockerfile.jetson) 会为 JetPack 6.2 从源码构建支持 CUDA 的 `torch`/`torchcodec` —— 该文件由社区维护，预构建镜像请参见 [`ravediamond/lerobot-jetson`](https://github.com/ravediamond/lerobot-jetson)，背景信息请参见 issue [#819](https://github.com/huggingface/lerobot/issues/819)。

如果您的平台支持 TorchCodec，请使用以下任一方法安装 `ffmpeg`：

<!-- prettier-ignore-start -->

<hfoptions id="install_ffmpeg">
<hfoption id="conda (any PyTorch version)">

在您的 conda 环境中安装 `ffmpeg`。此操作适用于**所有 PyTorch 版本**，并且**在 PyTorch < 2.10 时是必需的**：

```bash
conda install ffmpeg -c conda-forge
```

> [!TIP]
> 这通常会安装带有 `libsvtav1` 编码器的 `ffmpeg 8.X`。如果您遇到问题（例如缺少 `libsvtav1` —— 可使用 `ffmpeg -encoders` 检查 —— 或与 `torchcodec` 版本不匹配），可以使用以下命令显式安装 `ffmpeg 7.1.1`：
>
> ```bash
> conda install ffmpeg=7.1.1 -c conda-forge
> ```

</hfoption>
<hfoption id="uv (PyTorch >= 2.10 only)">

自 **PyTorch >= 2.10**（TorchCodec ≥ 0.10）开始，TorchCodec 可以动态链接到系统级安装的 `ffmpeg`。这在使用 `uv` 或其他非 `conda` 环境管理器时很有用：

```bash
# Ubuntu/Debian
sudo apt install ffmpeg

# macOS (Apple Silicon)
brew install ffmpeg
```

> [!IMPORTANT]
> 系统级 `ffmpeg` **仅在 PyTorch >= 2.10 下受支持**（TorchCodec ≥ 0.10）。对于较旧的 PyTorch 版本，您**必须**改用 `conda install ffmpeg -c conda-forge`。

</hfoption>
</hfoptions>
<!-- prettier-ignore-end -->

## 步骤 3：安装 LeRobot 🤗[[step-3-install-lerobot]]

基础 `lerobot` 安装特意保持**轻量**——它仅包含核心 ML 依赖项（PyTorch、torchvision、numpy、opencv、einops、draccus、huggingface-hub、gymnasium、safetensors）。较重的依赖项被置于可选扩展包之后，因此您只需安装所需内容。

### 从源码安装[[from-source]]

首先，克隆仓库并进入该目录：

```bash
git clone https://github.com/huggingface/lerobot.git
cd lerobot
```

然后，以可编辑模式安装该库。如果您计划为代码做贡献，这会很有用。

<!-- prettier-ignore-start -->
<hfoptions id="install_lerobot_src">
<hfoption id="conda">
```bash
pip install -e ".[core_scripts]"  # 用于机器人工作流程（录制、回放、校准）
pip install -e ".[training]"      # 用于训练策略（policy）
pip install -e ".[all]"           # 全部内容（所有策略、环境、硬件、开发工具）
```
</hfoption>
<hfoption id="uv">
```bash
uv pip install -e ".[core_scripts]"  # 用于机器人工作流程（录制、回放、校准）
uv pip install -e ".[training]"      # 用于训练策略（policy）
uv pip install -e ".[all]"           # 全部内容（所有策略、环境、硬件、开发工具）
```
</hfoption>
</hfoptions>
<!-- prettier-ignore-end -->

<hfoptions id="install_lerobot_pypi">
<hfoption id="conda">
```bash
pip install lerobot
```

```bash

```

_此安装仅包含核心 ML 依赖项。对于大多数工作流程，您都需要添加扩展包。_

**功能扩展包：**
LeRobot 提供了**按功能划分的扩展包（feature-scoped extras）**，它们对应常见工作流程。如果您使用 `uv`，请将以下命令中的 `pip install` 替换为 `uv pip install`。

| 扩展包     | 增加的内容                                  | 典型使用场景          |
| ---------- | ------------------------------------------- | --------------------- |
| `dataset`  | `datasets`、`av`、`torchcodec`、`jsonlines` | 加载和创建数据集      |
| `training` | `dataset` + `accelerate`、`wandb`           | 训练策略（policy）    |
| `hardware` | `pynput`、`pyserial`、`deepdiff`            | 连接真实机器人        |
| `viz`      | `rerun-sdk`                                 | 录制/评估期间的可视化 |

**组合扩展包（Composite Extras）** 会将功能扩展包组合起来，供常见 CLI 脚本使用：

| 组合扩展包     | 包含                           | 典型使用场景                                            |
| -------------- | ------------------------------ | ------------------------------------------------------- |
| `core_scripts` | `dataset` + `hardware` + `viz` | `lerobot-record`、`lerobot-replay`、`lerobot-calibrate` |
| `evaluation`   | `av`                           | `lerobot-eval`（根据需要添加策略 + 环境扩展包）         |
| `dataset_viz`  | `dataset` + `viz`              | `lerobot-dataset-viz`、`lerobot-imgtransform-viz`       |

```bash
pip install 'lerobot[core_scripts]'          # 录制、回放、校准
pip install 'lerobot[training]'              # 训练策略
pip install 'lerobot[core_scripts,training]' # 录制 + 训练
pip install 'lerobot[all]'                   # 全部内容
```

**策略（policy）、环境和硬件扩展包**仍可用于特定的依赖项：

```bash
pip install 'lerobot[pi]'             # Pi0/Pi0.5/Pi0-FAST 策略依赖
pip install 'lerobot[smolvla]'        # SmolVLA 策略依赖
pip install 'lerobot[diffusion]'      # 扩散策略依赖（diffusers）
pip install 'lerobot[aloha,pusht]'    # 仿真环境
pip install 'lerobot[feetech]'        # Feetech 电机支持
```

_可组合多个扩展包（例如 `.[core_scripts,pi,pusht]`）。完整可用扩展包列表请参阅 `pyproject.toml`。_

### PyTorch CUDA 变体（仅限 Linux）[[pytorch-cuda-variant-linux-only]]

在 Linux 上，安装路径决定了您会获得哪个 CUDA wheel。macOS 和 Windows 安装使用 PyPI 默认值（分别为 MPS / CPU / CUDA-Windows wheel），并可跳过本节。

<!-- prettier-ignore-start -->

<hfoptions id="cuda_variant">
<hfoption id="uv-source">

**通过 `uv` 进行源码安装（`uv sync` 或 `uv pip install -e .`）**

`torch` 和 `torchvision` 被项目固定到 **CUDA 12.8** PyTorch 索引（`https://download.pytorch.org/whl/cu128`，最低驱动版本 **570.86**）——涵盖 Ampere/Ada/Hopper/Blackwell GPU。对于典型 NVIDIA 配置，无需执行任何操作。

若要覆盖为其他 CUDA 变体：

```bash
uv pip install --force-reinstall torch torchvision \
    --index-url https://download.pytorch.org/whl/cu126   # 较旧的驱动；或在驱动 ≥ 580 的 Blackwell 上使用 cu130
```

</hfoption>
<hfoption id="pip-conda">

**通过 `pip`/`conda` 进行源码安装，或从 PyPI 执行 `pip install lerobot`**

PyPI 默认的 `torch` wheel 目前是捆绑 cu130 的 Linux wheel，最低驱动版本为 **580.65**。

若要选择特定 CUDA 变体：

**使用 `pip` 或 `conda`**——先通过显式索引安装 torch，然后安装 lerobot：

```bash
pip install --index-url https://download.pytorch.org/whl/cu128 torch torchvision
pip install -e ".[all]"          # 源码
# — 或 —
pip install lerobot              # 从 PyPI 安装
```

**使用 `uv` 从 PyPI 安装**——通过 `--torch-backend` 一行命令完成（uv ≥ 0.6）：

```bash
uv pip install --torch-backend cu128 lerobot
```

支持的值包括 `auto`、`cpu`、`cu126`、`cu128`、`cu129`、`cu130`，以及各种 `rocm*` 和 `xpu`。可根据您的驱动按需切换。

</hfoption>
</hfoptions>
<!-- prettier-ignore-end -->

### 故障排除[[troubleshooting]]

如果您遇到构建错误，可能需要安装额外的系统依赖项：`cmake`、`build-essential` 和 `ffmpeg libs`。
要在 Linux 上安装这些依赖，请运行：

```bash
sudo apt-get install cmake build-essential python3-dev pkg-config libavformat-dev libavcodec-dev libavdevice-dev libavutil-dev libswscale-dev libswresample-dev libavfilter-dev
```

其他系统请参阅：[Compiling PyAV](https://pyav.org/docs/develop/overview/installation.html#bring-your-own-ffmpeg)

## 可选依赖[[optional-dependencies]]

LeRobot 为特定功能提供可选扩展包。可以组合多个扩展包（例如 `.[aloha,feetech]`）。所有可用扩展包请参阅 `pyproject.toml`。如果您使用 `uv`，请将以下命令中的 `pip install` 替换为 `uv pip install`。

### 仿真环境[[simulations]]

安装环境包：`aloha`（[gym-aloha](https://github.com/huggingface/gym-aloha)）或 `pusht`（[gym-pusht](https://github.com/huggingface/gym-pusht)）。
这些会自动包含 `dataset` 扩展包。

```bash
pip install -e ".[aloha]" # 或例如使用 "[pusht]"
```

### 电机控制[[motor-control]]

对于 Koch v1.1，安装 Dynamixel SDK；对于 SO100/SO101/Moss，安装 Feetech SDK。

```bash
pip install -e ".[feetech]" # 或例如使用 "[dynamixel]"
```

### 实验跟踪[[experiment-tracking]]

`training` 扩展包中包含 Weights and Biases。要使用 [Weights and Biases](https://docs.wandb.ai/quickstart) 进行实验跟踪，请登录：

```bash
wandb login
```

如果您的机器人尚未准备好，现在可以组装它，并在左侧查找您的机器人类型。然后按照下方链接，将 LeRobot 与您的机器人配合使用。
