# π₀（Pi0）[[-pi0]]

π₀ 是一个**用于通用机器人控制的视觉-语言-动作（Vision-Language-Action）模型**，来自 Physical Intelligence。LeRobot 实现改编自他们的开源 [OpenPI](https://github.com/Physical-Intelligence/openpi) 仓库。

## 模型概览[[model-overview]]

π₀ 代表了机器人领域的一项突破，是 [Physical Intelligence](https://www.physicalintelligence.company/blog/pi0) 开发的第一个通用机器人基础模型。传统机器人程序是针对重复动作编程的专用型程序，而 π₀ 被设计为通用策略（policy），能够理解视觉输入、解释自然语言指令，并控制多种不同机器人完成多样化任务。

### Physical Intelligence 的愿景[[the-vision-for-physical-intelligence]]

正如 Physical Intelligence 所描述，尽管 AI 在数字领域取得了显著成功，从下棋到药物发现，但人类智能在物理世界中仍然大幅超越 AI。套用莫拉维克悖论（Moravec's paradox）的说法，赢得一盘国际象棋对 AI 来说是“简单”问题，但叠一件衬衫或清理一张桌子却需要解决一些有史以来最困难的工程问题。π₀ 代表了朝着开发人工物理智能迈出的第一步，这种智能使用户能够直接要求机器人执行任何他们想要的任务，就像使用大型语言模型一样。

### 架构与方法[[architecture-and-approach]]

π₀ 结合了多项关键创新：

- **流匹配（Flow Matching）**：使用一种新颖方法，通过流匹配（扩散模型的一种变体）为预训练的视觉-语言模型（VLM）增加连续动作输出
- **跨具身训练（Cross-Embodiment Training）**：在来自 8 种不同机器人平台的数据上训练，包括 UR5e、Bimanual UR5e、Franka、Bimanual Trossen、Bimanual ARX、Mobile Trossen 和 Mobile Fibocom
- **互联网规模预训练（Internet-Scale Pre-training）**：从预训练的 3B 参数视觉-语言模型中继承语义知识
- **高频控制（High-Frequency Control）**：输出最高 50 Hz 的电机命令，用于实时灵巧操作

## 安装要求[[installation-requirements]]

1. 按照我们的[安装指南](./installation)安装 LeRobot。
2. 运行以下命令安装 Pi0 依赖项：

   ```bash
   pip install -e ".[pi]"
   ```

## 训练数据与能力[[training-data-and-capabilities]]

π₀ 在迄今为止最大的机器人交互数据集上训练，结合了三大关键数据源：

1. **互联网规模预训练**：来自网络的视觉-语言数据，用于语义理解
2. **Open X-Embodiment 数据集**：开源机器人操作数据集
3. **Physical Intelligence 数据集**：涵盖 8 种不同机器人的大型多样化灵巧任务数据集

## 使用方法[[usage]]

要在 LeRobot 中使用 π₀，请将策略（policy）类型指定为：

```python
policy.type=pi0
```

## 训练[[training]]

要训练 π₀，你可以使用标准 LeRobot 训练脚本并配置相应参数：

```bash
lerobot-train \
    --dataset.repo_id=your_dataset \
    --policy.type=pi0 \
    --output_dir=./outputs/pi0_training \
    --job_name=pi0_training \
    --policy.pretrained_path=lerobot/pi0_base \
    --policy.repo_id=your_repo_id \
    --policy.compile_model=true \
    --policy.gradient_checkpointing=true \
    --policy.dtype=bfloat16 \
    --policy.freeze_vision_encoder=false \
    --policy.train_expert_only=false \
    --steps=3000 \
    --policy.device=cuda \
    --batch_size=32
```

### 关键训练参数[[key-training-parameters]]

- **`--policy.compile_model=true`**：启用模型编译以加速训练
- **`--policy.gradient_checkpointing=true`**：显著降低训练期间的内存占用
- **`--policy.dtype=bfloat16`**：使用混合精度训练以提高效率
- **`--batch_size=32`**：训练批次大小，请根据你的 GPU 内存进行调整
- **`--policy.pretrained_path=lerobot/pi0_base`**：要微调的基础 π₀ 模型，选项包括：
  - [lerobot/pi0_base](https://huggingface.co/lerobot/pi0_base)
  - [lerobot/pi0_libero](https://huggingface.co/lerobot/pi0_libero)（专门在 Libero 数据集上训练）

### 训练参数说明[[training-parameters-explained]]

| 参数                    | 默认值  | 说明                     |
| ----------------------- | ------- | ------------------------ |
| `freeze_vision_encoder` | `false` | 不冻结视觉编码器         |
| `train_expert_only`     | `false` | 不冻结 VLM，训练所有参数 |

**💡 提示**：设置 `train_expert_only=true` 会冻结 VLM，仅训练动作专家（action expert）和投影层，从而可以在降低内存占用的情况下进行微调。

## 相对动作[[relative-actions]]

默认情况下，π₀ 预测绝对动作。你可以启用**相对动作**，让模型预测相对于当前机器人状态的偏移量。对于某些设置，这可以提高训练稳定性。

要使用相对动作，请先通过 CLI 在相对空间中重新计算数据集统计信息：

```bash
lerobot-edit-dataset \
    --repo_id your_dataset \
    --operation.type recompute_stats \
    --operation.relative_action true \
    --operation.chunk_size 50 \
    --operation.relative_exclude_joints "['gripper']" \
    --push_to_hub true
```

或在 Python 中等价地执行：

```python
from lerobot.datasets import LeRobotDataset, recompute_stats

dataset = LeRobotDataset("your_dataset")
recompute_stats(dataset, relative_action=True, chunk_size=50, relative_exclude_joints=["gripper"])
dataset.push_to_hub()
```

`chunk_size` 应与你的策略（policy）的 `chunk_size` 匹配（π₀ 默认为 50）。`relative_exclude_joints` 列出应保持绝对空间的关节名称（例如夹爪命令）。使用 `--push_to_hub true` 将更新后的统计信息上传到 Hub。

然后启用相对动作进行训练：

```bash
lerobot-train \
    --dataset.repo_id=your_dataset \
    --policy.type=pi0 \
    --policy.use_relative_actions=true \
    --policy.relative_exclude_joints='["gripper"]' \
    ...
```
