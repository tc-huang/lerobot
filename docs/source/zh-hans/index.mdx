**面向现实世界机器人的最先进的机器学习技术**

🤗 LeRobot 提供硬件无关、原生 Python 的接口，用于控制真实机器人——从 SO-ARM101 等经济实惠的机械臂到完整的人形机器人。它还提供用于录制、存储和分享这些机器人所生成数据集的工具。每个数据集都使用标准化的 **LeRobotDataset** 格式（同步视频 + 动作/状态数据），并可直接从 [Hugging Face Hub](https://huggingface.co/lerobot) 流式传输。

🤗 在这些数据之上，LeRobot 实现了最先进的策略（policy）——从 ACT 等轻量级模仿学习模型到 π₀ 和 SmolVLA 等大型视觉-语言-动作（vision-language-action）模型——所有这些都可以通过同样少量 CLI 命令进行训练、分享和部署。

目标：降低机器人技术的入门门槛，让每个人都能为共享数据集和预训练模型做出贡献，并从中受益。

## 工作原理[[how-it-works]]

**遥操作（teleoperation） → 录制 → 训练 → 部署**

1. **遥操作**——亲自控制机器人（使用主臂（leader arm）、键盘或手机），让它从你的动作中学习。
2. **录制**——每次演示都会保存为一个数据集：同步的摄像头视频以及你执行的动作。
3. **训练**——策略（policy）（即用于控制机器人的神经网络）学习模仿你的演示。
4. **部署**——在机器人上运行训练好的策略，看着它自行完成任务。

## 常见问题[[common-problems]]

遇到问题了吗？以下是一些最常见的情况：

- **摄像头画面模糊或无法使用**——光线比分辨率更重要。请参阅[摄像头](./cameras)指南。
- **构建或安装错误**（`cmake`、`ffmpeg`、CUDA）——请参阅[安装指南](./installation#troubleshooting)的故障排除部分。
- **不确定哪种策略（policy）适合你的 GPU**——请查看[计算与硬件指南](./hardware_guide)。
- **仍然卡住了？** 在 [Discord](https://discord.gg/s3KuuzsPFb) 上提问——社区（以及 LeRobot 团队）会提供帮助。
