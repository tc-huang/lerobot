**面向现实世界机器人的最先进的机器学习技术**

🤗 LeRobot 提供硬件无关（hardware-agnostic）、Python 原生（Python-native）的接口，用于控制真实机器人——从 SO-ARM101 这类经济实惠的机械臂到完整的人形机器人（humanoids）。此外，还提供记录、存储和共享它们所生成数据集（dataset）的工具。每个数据集都采用标准化的 **LeRobotDataset** 格式（同步视频 + 动作/状态数据），并且可以直接从 [Hugging Face Hub](https://huggingface.co/lerobot) 流式加载。

🤗 在这些数据之上，LeRobot 实现了最先进的策略（policy）——从 ACT 这类轻量级模仿学习（imitation learning）模型，到 π₀ 和 SmolVLA 这类大型视觉-语言-动作（vision-language-action）模型——它们都可以通过同样少数几个 CLI 命令进行训练、共享和部署。

目标：降低机器人技术的准入门槛，让每个人都能为共享数据集（dataset）和预训练模型（pretrained model）做出贡献并从中受益。

## 工作原理[[how-it-works]]

**遥操作（Teleoperate）→ 记录（Record）→ 训练（Train）→ 部署（Deploy）**

1. **遥操作（Teleoperate）**——自己控制机器人（使用主臂（leader arm）、键盘或手机），以便它从你的动作中学习。
2. **记录（Record）**——每次演示（demonstration）都会保存为数据集（dataset）：同步的摄像头视频以及你执行的动作。
3. **训练（Train）**——策略（policy）——也就是控制机器人的神经网络（neural network）——会学习模仿你的演示。
4. **部署（Deploy）**——在机器人上运行训练好的策略（policy），看它自行完成任务。

## 常见问题[[common-problems]]

遇到问题？以下是一些最常见的情况：

- **摄像头画面（camera footage）模糊或不可用**——光照（lighting）比分辨率（resolution）更重要。请参阅[摄像头指南](./cameras)。
- **构建或安装错误**（`cmake`、`ffmpeg`、CUDA）——请参阅[安装指南](./installation#troubleshooting)的故障排除（Troubleshooting）部分。
- **不确定哪种策略（policy）适合你的 GPU**——请查看[计算与硬件指南](./hardware_guide)。
- **仍然卡住了？** 请在 [Discord](https://discord.gg/s3KuuzsPFb) 上提问——社区（以及 LeRobot 团队）随时为你提供帮助。
