# 使用数据集工具[[using-dataset-tools]]

本指南介绍 LeRobot 中用于修改和编辑现有数据集的工具。

## 概述[[overview]]

LeRobot 提供了以下几种数据集操作工具：

1. **删除片段（Delete Episodes）** - 从数据集中删除特定片段
2. **拆分数据集（Split Dataset）** - 将数据集划分为多个较小的数据集
3. **合并数据集（Merge Datasets）** - 将多个数据集合并为一个。各数据集必须具有相同的特征，片段按 `repo_ids` 中指定的顺序拼接
4. **添加特征（Add Features）** - 向数据集添加新特征
5. **删除特征（Remove Features）** - 从数据集中删除特征
6. **修改任务（Modify Tasks）** - 更改与片段关联的自然语言任务描述
7. **转换为视频（Convert to Video）** - 将基于图像的数据集转换为视频格式以节省存储空间（RGB 和深度相机使用单独的编码器进行编码）
8. **重新编码视频（Re-encode Videos）** - 使用新的编码器设置重新编码现有视频数据集的 RGB 和/或深度流
9. **显示数据集信息（Show the Info of Datasets）** - 显示数据集的摘要信息，如片段数量等

核心实现位于 `lerobot.datasets.dataset_tools`。
有关如何使用工具 API 的示例脚本位于 `examples/dataset/use_dataset_tools.py`。

## 命令行工具：lerobot-edit-dataset[[command-line-tool-lerobot-edit-dataset]]

`lerobot-edit-dataset` 是用于编辑数据集的命令行脚本，支持删除片段、拆分数据集、合并数据集、添加特征、删除特征以及将图像数据集转换为视频格式。

运行 `lerobot-edit-dataset --help` 可查看各操作的配置说明。

### 使用示例[[usage-examples]]

#### 删除片段[[delete-episodes]]

从数据集中删除特定片段，适用于过滤不需要的数据。

```bash
# 删除第 0、2、5 个片段（直接修改原数据集）
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"

# 删除片段并保存到新数据集（保留原数据集）
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --new_repo_id lerobot/pusht_after_deletion \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"
```

#### 拆分数据集[[split-dataset]]

将数据集划分为多个子集。

```bash
# 按比例拆分（例如：60% 训练集、20% 验证集、20% 测试集）
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type split \
    --operation.splits '{"train": 0.6, "val": 0.2, "test": 0.2}'

# 按指定片段索引拆分
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type split \
    --operation.splits '{"task1": [0, 1, 2, 3], "task2": [4, 5]}'
```

拆分名称没有限制，可由用户自定义。结果数据集以原 repo id 加拆分名称的形式保存，例如 `lerobot/pusht_train`、`lerobot/pusht_task1`、`lerobot/pusht_task2`。

#### 合并数据集[[merge-datasets]]

将多个数据集合并为一个。

```bash
# 将训练集和验证集合并回一个数据集
lerobot-edit-dataset \
    --repo_id lerobot/pusht_merged \
    --operation.type merge \
    --operation.repo_ids "['lerobot/pusht_train', 'lerobot/pusht_val']"
```

#### 删除特征[[remove-features]]

从数据集中删除特征。

```bash
# 删除一个摄像头特征
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type remove_feature \
    --operation.feature_names "['observation.images.top']"
```

#### 修改任务[[modify-tasks]]

更改与片段关联的自然语言任务描述。这有助于修正拼写错误、统一措辞或重新标注片段。

> [!WARNING]
> `modify_tasks` 会**就地**修改数据集（更新 `meta/tasks.parquet`、数据文件中的 `task_index` 列、片段元数据中的 `tasks` 列，以及 `meta/info.json` 中的 `total_tasks`）。此操作会忽略 `--new_repo_id` 和 `--new_root` 参数。

```bash
# 为所有片段设置单一任务
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type modify_tasks \
    --operation.new_task "Pick up the cube and place it"

# 为特定片段设置不同任务
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type modify_tasks \
    --operation.episode_tasks '{"0": "Task A", "1": "Task B", "2": "Task A"}'

# 替换出现的现有任务字符串
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type modify_tasks \
    --operation.task_replacements '{"Pick up the red cube": "Lift the red cube"}'

# 在一次运行中组合多种模式
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type modify_tasks \
    --operation.new_task "Default task" \
    --operation.task_replacements '{"Pick up the red cube": "Lift the red cube"}' \
    --operation.episode_tasks '{"5": "Special task for episode 5"}'
```

**参数说明：**

- `new_task`：用作未另行覆盖片段的默认任务的单个任务字符串。
- `episode_tasks`：从片段索引到任务字符串的映射。
- `task_replacements`：从现有任务字符串到其替换内容的映射，应用于当前任务与某个键匹配的片段。每个键都必须是数据集中的现有任务。

这些模式可以在一次运行中组合使用。对于每个片段，任务按以下优先级解析：

`episode_tasks` > `task_replacements` > `new_task` > 原始任务

必须至少指定 `new_task`、`episode_tasks` 或 `task_replacements` 之一。如果某个片段最终没有任务，则会引发错误。

#### 转换为视频[[convert-to-video]]

将基于图像的数据集转换为视频格式，生成一个新的 LeRobotDataset，其中图像以视频形式存储。此操作可减少存储占用并提升数据加载性能。新数据集与原数据集结构完全相同，但图像以 LeRobot 标准格式编码为 MP4 视频。

```bash
# 仅本地保存：指定自定义输出目录（不推送到 Hub）
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir /path/to/output/pusht_video

# 使用新 repo_id 保存（本地存储）
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --new_repo_id lerobot/pusht_video \
    --operation.type convert_image_to_video

# 转换并推送到 Hugging Face Hub
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --new_repo_id lerobot/pusht_video \
    --operation.type convert_image_to_video \
    --push_to_hub true

# 使用自定义视频编解码器和质量设置进行转换
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir outputs/pusht_video \
    --operation.rgb_encoder.vcodec libsvtav1 \
    --operation.rgb_encoder.pix_fmt yuv420p \
    --operation.rgb_encoder.g 2 \
    --operation.rgb_encoder.crf 30

# 转换包含深度图的数据集，并自定义深度编码器
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir outputs/pusht_video \
    --operation.depth_encoder.depth_min 0.01 \
    --operation.depth_encoder.depth_max 10.0 \
    --operation.depth_encoder.use_log true

# 仅转换指定片段
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir outputs/pusht_video \
    --operation.episode_indices "[0, 1, 2, 5, 10]"

# 使用多个 worker 并行处理
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir outputs/pusht_video \
    --operation.num_workers 8

# 对内存受限的系统，可指定批处理限制：
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_to_video \
    --operation.max_episodes_per_batch 50 \
    --operation.max_frames_per_batch 10000
```

**参数说明：**

- `output_dir`：自定义输出目录（可选 - 默认使用 `new_repo_id` 或 `{repo_id}_video`）
- `rgb_encoder`：应用于 RGB 摄像头的视频编码器设置 —— 所有子字段均可通过 `--operation.rgb_encoder.<field>` 访问。详情请参阅[视频编码参数](./video_encoding_parameters)。
- `depth_encoder`：应用于深度图摄像头（例如来自 Intel RealSense）的视频编码器设置。除了标准编码器字段外，它还提供深度量化调节项（`depth_min`、`depth_max`、`shift`、`use_log`），可通过 `--operation.depth_encoder.<field>` 访问。这些量化设置会持久化到数据集元数据中，以便在加载时将深度去量化回物理单位。详情请参阅[深度流](./video_encoding_parameters#depth-streams)一节。
- `episode_indices`：要转换的特定片段列表（默认：全部片段）
- `num_workers`：用于处理的并行 worker 数量（默认：4）

**注意：** 生成的数据集是完整的 LeRobotDataset，所有摄像头均以视频形式编码至 `videos/` 目录，parquet 文件仅包含元数据（不含原始图像数据）。深度图摄像头会被自动检测并路由到 `depth_encoder`，而 RGB 摄像头使用 `rgb_encoder`。所有片段、统计信息和任务均会保留。

#### 重新编码视频[[re-encode-videos]]

使用不同的编码器设置重新编码现有视频数据集的视频，而无需回到原始帧。RGB 视频使用 `rgb_encoder`，深度视频使用 `depth_encoder`。只需提供你想要重新编码的编码器；另一种流类型保持不变。

```bash
# 使用新设置重新编码所有 RGB 视频（默认保存到 lerobot/pusht_reencoded）
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type reencode_videos \
    --operation.rgb_encoder.vcodec h264 \
    --operation.rgb_encoder.pix_fmt yuv420p \
    --operation.rgb_encoder.crf 23

# 重新编码包含深度图的数据集中的 RGB 和深度视频
lerobot-edit-dataset \
    --repo_id lerobot/pusht_depth \
    --operation.type reencode_videos \
    --operation.rgb_encoder.vcodec h264 \
    --operation.depth_encoder.crf 50
```

**参数说明：**

- `rgb_encoder`：应用于每个 RGB 视频的编码器设置。省略则跳过重新编码 RGB 视频。
- `depth_encoder`：应用于每个深度视频的编码器设置。省略则跳过重新编码深度视频。
- `num_workers`：用于处理的并行 worker 数量。

> [!NOTE]
> 重新编码深度视频时，现有深度量化参数（`depth_min`、`depth_max`、`shift`、`use_log`）和 `is_depth_map` 标志会被**保留**——重新编码只会更改所存储流的编解码器/质量，而不会改变加载时深度去量化的方式。

### 显示数据集信息[[show-the-information-of-datasets]]

显示数据集信息，如片段数量、帧数、文件大小等。
此操作不会对数据集做任何修改。

```bash

# 不显示特征详情
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type info \

# 显示特征详情
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type info \
    --operation.show_features true

```

**参数说明：**

- `parameters`：控制是否显示特征详情的标志（默认：false）

### 推送到 Hub[[push-to-hub]]

在任意命令中添加 `--push_to_hub true` 标志，可将结果数据集自动上传至 Hugging Face Hub：

```bash
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --new_repo_id lerobot/pusht_after_deletion \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]" \
    --push_to_hub true
```

此外还有一个用于向数据集添加特征的工具，但目前 `lerobot-edit-dataset` 尚未涵盖该工具。

# 数据集可视化[[dataset-visualization]]

## 在线可视化[[online-visualization]]

使用 `lerobot` 录制数据集时，除非另行指定，数据集会自动上传至 Hugging Face Hub。可通过我们的 **LeRobot 数据集可视化工具** 在线查看数据集：
https://huggingface.co/spaces/lerobot/visualize_dataset

## 本地可视化[[local-visualization]]

也可使用命令行工具在本地可视化数据集中的片段。

**从 Hugging Face Hub 加载：**

```bash
lerobot-dataset-viz \
    --repo-id lerobot/pusht \
    --episode-index 0
```

对于私有或受限数据集，请先使用 `hf auth login` 进行身份验证，或设置 `HF_TOKEN` 环境变量。Hub 客户端随后会自动发现凭据；无需提供 token 参数。

**从本地文件夹加载：**
添加 `--root` 选项并设置 `--mode local`。例如，在 `./my_local_data_dir/lerobot/pusht` 中搜索：

```bash
lerobot-dataset-viz \
    --repo-id lerobot/pusht \
    --root ./my_local_data_dir \
    --mode local \
    --episode-index 0
```

执行后，工具将打开 `rerun.io`，展示所选片段的摄像头画面、机器人状态及动作。

若要改用 [Foxglove](https://foxglove.dev) 而不是 Rerun，请安装额外依赖并添加 `--display-mode foxglove`。这会启动一个 WebSocket 服务器（将 Foxglove 应用连接到 `ws://127.0.0.1:8765`），将片段作为可定位的时间线提供，你可以播放/暂停和拖动浏览。

如需高级用法（包括可视化远程服务器上的数据集），请运行：

```bash
lerobot-dataset-viz --help
```
