# 遥操作器[[teleoperators]]

遥操作器（teleoperator）为机器人产生要跟随的动作——主臂、游戏手柄、键盘或手机。它们都实现 [`Teleoperator`] 接口，因此基于该接口编写的录制脚本可与任何输入设备配合使用。

参见 [手机遥操作](../phone_teleop) 和 [Isaac Teleop](../isaac_teleop) 了解设置指南，并参见 [机器人模仿学习](../il_robots) 了解录制工作流。
