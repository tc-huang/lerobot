# 配置[[configuration]]

LeRobot 配置是普通的 dataclass，由 [draccus](https://github.com/dlwh/draccus) 解析，因此每个字段都可以通过 CLI 设置。[`TrainPipelineConfig`] 是用于 `lerobot-train` 的顶层对象。

多态配置（策略、机器人、环境）使用 `draccus.ChoiceRegistry`：子类通过 `@register_subclass("name")` 注册自身，随后可在命令行中通过该名称选择。
