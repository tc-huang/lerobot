# 配置[[configuration]]

LeRobot 配置是由 [draccus](https://github.com/dlwh/draccus) 解析的普通数据类（dataclasses），因此每个字段都可以从命令行界面（CLI）设置。[`TrainPipelineConfig`] 是 `lerobot-train` 的顶层对象。

多态配置（polymorphic configs）（例如策略（policy）、机器人、环境）使用 `draccus.ChoiceRegistry`：子类通过 `@register_subclass("name")` 注册自身，然后就可以在命令行上按该名称选择。
