# 处理器[[processors]]

处理器（Processors）是机器人、数据集和策略（policy）之间的数据转换层。管道（pipeline）是一系列 [`ProcessorStep`] 组成的链；每个步骤都声明它如何转换数据以及特征契约（feature contract）。

有关概念，请参阅[机器人处理器简介](../introduction_processors)；要编写步骤，请参阅[实现你自己的处理器](../implement_your_own_processor)；当管道行为异常时，请参阅[调试处理器管道](../debug_processor_pipeline)。
