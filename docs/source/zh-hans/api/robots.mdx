# 机器人[[robots]]

LeRobot 中的每个机器人都会实现 [`Robot`] 接口：连接、读取观测（observation）、发送动作、
断开连接。基于该接口编写策略（policy）或录制脚本，就意味着无需任何改动即可适用于任何受支持的
机械臂。

本页是自动生成的参考文档。有关接线、校准和首次运行的说明，请从硬件指南入手 —— [SO-101](../so101)、
[LeKiwi](../lekiwi)、[Hope Jr](../hope_jr)、[Reachy 2](../reachy2)、
[OpenArm](../openarm) —— 或参阅[机器人模仿学习](../il_robots)了解端到端工作流程。要添加
自己的机器人，请参阅[自带硬件](../integrate_hardware)。
