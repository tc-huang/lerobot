# 相机[[cameras]]

相机提供策略（policy）所看到的图像观测（observation）。每个后端——OpenCV、Intel RealSense、Reachy 2——
都实现 [`Camera`] 接口，因此更换硬件不会改变读取帧（frame）的代码。

有关选择和配置相机的说明，请参阅[相机指南](../cameras)；有关核心设备之外的设备，请参阅
[第三方相机与传感器](../third_party_sensors)。
