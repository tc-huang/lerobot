# 策略[[policies]]

每个策略（policy）都继承 [`PreTrainedPolicy`]，后者将 `torch.nn.Module` 与 Hub mixin 组合在一起，因此任何策略都可以通过相同的两次调用推送到 Hugging Face Hub 并从 Hugging Face Hub 加载。

每个策略都有自己的指南，其中包含训练配方（training recipes）和结果——[ACT](../act)、[SmolVLA](../smolvla)、[π₀](../pi0)、[π₀.₅](../pi05)，其余策略列在“策略”下。要添加一个策略，请参阅[添加策略](../bring_your_own_policies)。
