# 数据集[[datasets]]

[`LeRobotDataset`] 是每个 LeRobot 脚本读取和写入的格式。它能够感知片段（episode），实时解码视频观测（observation），并能往返于 Hugging Face Hub。

请参阅[使用 LeRobotDataset](../lerobot-dataset-v3)了解格式与常用操作，[移植大型数据集](../porting_datasets_v3)了解迁移，以及[工具](../tools)了解 CLI。
