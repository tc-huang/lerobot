# SO-100[[so-100]]

在以下步骤中，我们将说明如何组装 SO-100 机器人。

## 获取零件[[source-the-parts]]

请按照这个 [README](https://github.com/TheRobotStudio/SO-ARM100/blob/main/SO100.md) 操作。它包含物料清单（bill of materials），其中附有获取零件的链接，以及 3D 打印零件的说明。如果你第一次打印或没有 3D 打印机，它也会提供建议。

## 安装 LeRobot 🤗[[install-lerobot-]]

要安装 LeRobot，请遵循我们的[安装指南](./installation)

除了这些说明外，你还需要安装 Feetech SDK：

```bash
pip install -e ".[feetech]"
```

## 配置电机[[configure-the-motors]]

**注意：**
与 SO-101 不同，机械臂组装完成后，电机连接器就不容易接触到了，因此必须提前完成配置步骤。

### 1. 查找与每条机械臂关联的 USB 端口[[1-find-the-usb-ports-associated-with-each-arm]]

要查找每个总线舵机适配器（bus servo adapter）的端口，请运行以下脚本：

```bash
lerobot-find-port
```

<hfoptions id="example">
<hfoption id="Mac">

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
Remove the USB cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/tty.usbmodem575E0032081
Reconnect the USB cable.
```

找到的端口是：`/dev/tty.usbmodem575E0032081`，对应你的主臂或从臂。

</hfoption>
<hfoption id="Linux">

在 Linux 上，你可能需要运行以下命令来授予 USB 端口访问权限：

```bash
sudo chmod 666 /dev/ttyACM0
sudo chmod 666 /dev/ttyACM1
```

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/ttyACM0', '/dev/ttyACM1']
Remove the usb cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/ttyACM1
Reconnect the USB cable.
```

找到的端口是：`/dev/ttyACM1`，对应你的主臂或从臂。

</hfoption>
</hfoptions>

### 2. 设置电机 ID 和波特率[[2-set-the-motors-ids-and-baudrates]]

每个电机通过总线上的唯一 ID 进行标识。全新电机通常带有默认 ID `1`。为了让电机与控制器之间的通信正常工作，我们首先需要为每个电机设置一个唯一的、不同的 ID。此外，总线上数据传输的速度由波特率（baudrate）决定。为了能够相互通信，控制器和所有电机都需要配置相同的波特率。

为此，我们首先需要将控制器与每个电机单独连接来设置这些参数。由于我们会将这些参数写入电机内部存储器的非易失性区域（EEPROM），因此只需执行一次。

如果你要复用来自另一台机器人的电机，很可能也需要执行此步骤，因为 ID 和波特率可能不匹配。

#### 从臂[[follower]]

将计算机的 USB 线缆和电源连接到从臂的控制板。然后，使用上一步获得的端口运行以下命令或 API 示例。你还需要使用 `id` 参数为主臂命名。

有关如何设置电机 ID 的可视化参考，请参阅[此视频](https://huggingface.co/docs/lerobot/zh-hans/so101#setup-motors-video)，其中我们演示了 SO101 机械臂的流程。

<hfoptions id="setup_motors">
<hfoption id="Command">

```bash
lerobot-setup-motors \
    --robot.type=so100_follower \
    --robot.port=/dev/tty.usbmodem585A0076841  # <- 在此粘贴上一步找到的端口
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.so_follower import SO100Follower, SO100FollowerConfig

config = SO100FollowerConfig(
    port="/dev/tty.usbmodem585A0076841",
    id="my_awesome_follower_arm",
)
follower = SO100Follower(config)
follower.setup_motors()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

你应该会看到以下指令

```
Connect the controller board to the 'gripper' motor only and press enter.
```

按照指令，插入夹爪电机。确保它是唯一连接到控制板的电机，并且该电机本身尚未以菊花链方式连接到任何其他电机。当你按下 `[Enter]` 时，脚本会自动为该电机设置 ID 和波特率。

<details>
<summary>故障排除</summary>

如果此时出现错误，请检查线缆，并确保它们已正确插入：

<ul>
  <li>电源</li>
  <li>计算机与控制板之间的 USB 线缆</li>
  <li>从控制板到电机的 3 针线缆</li>
</ul>

如果你使用的是 Waveshare 控制板，请确保两个跳线设置在 `B` 通道（USB）上。

</details>

然后你应该会看到以下消息：

```
'gripper' motor id set to 6
```

接着是下一条指令：

```
Connect the controller board to the 'wrist_roll' motor only and press enter.
```

你可以断开控制板上的 3 针线缆，但可以保留另一端与夹爪电机的连接，因为它已经位于正确位置。现在，将另一根 3 针线缆插入腕部旋转电机，并将其连接到控制板。与前一个电机一样，请确保它是唯一连接到控制板的电机，并且该电机本身没有连接到任何其他电机。

按照指令对每个电机重复该操作。

> [!TIP]
> 在按 Enter 之前，请检查每一步的线缆连接。例如，在操作控制板时，电源线可能会断开。

完成后，脚本会直接结束，此时电机即可使用。现在，你可以将每个电机的 3 针线缆连接到下一个电机，并将第一个电机（id=1 的“肩部水平旋转”电机）的线缆连接到控制板，控制板现在可以安装到机械臂底座上。

## 校准[[calibrate]]

接下来，你需要校准机器人，以确保主臂和从臂处于相同物理位置时具有相同的位置值。
校准过程非常重要，因为它能让在一台机器人上训练的神经网络在另一台机器人上工作。

#### 从臂[[follower]]

运行以下命令或 API 示例来校准从臂：

<hfoptions id="calibrate_follower">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --robot.type=so100_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \ # <- 你机器人的端口
    --robot.id=my_awesome_follower_arm # <- 为机器人指定一个唯一名称
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.so_follower import SO100FollowerConfig, SO100Follower

config = SO100FollowerConfig(
    port="/dev/tty.usbmodem585A0076891",
    id="my_awesome_follower_arm",
)

follower = SO100Follower(config)
follower.connect(calibrate=False)
follower.calibrate()
follower.disconnect()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>
